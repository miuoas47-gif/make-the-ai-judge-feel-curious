A small program that writes one short text, built for make.fun's
"Make the AI judge feel curious" bounty. The text is a half-told story: a
lighthouse keeper who still lights a lamp no ship has needed in eleven
years — until one Tuesday, when it burned blue for nine seconds. A quiet
mystery, told plainly, that leaves the question open.

## Run it

```sh
python3 main.py
```

It writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt`
when the variable is not set). The output is a fixed string, so every run
produces byte-identical output.
